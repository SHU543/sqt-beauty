# 舒庆涛 · 作品集网页

## 怎么打开
双击 index.html，或右键 → 打开方式 → Chrome / Edge。纯静态，不需要服务器和网络。

## 目录
```
site/
├── index.html        页面正文（24 件作品）
├── css/style.css     全部样式
├── js/main.js        滚动淡入 / 图片灯箱 / 视频播放 / 卡片悬停动画
├── assets/img/       展示图 37 张
└── assets/video/     网页版视频 7 个
```

## 交互
- **卡片悬停**：动态设计那 4 件会开始循环播放（静止时显示封面图）
- **点击封面**：打开灯箱；影像作品直接播放全片，其余看大图（多图可切换）
- **播放徽标**：影像作品左下角是「▶ 播放全片」，动态作品是「▶ 悬停预览动画」

## 视频清单（7 个，共约 77 MB）
| 文件 | 用途 | 大小 |
|---|---|---|
| ae-film.mp4 / shiting.mp4 / chenmo.mp4 | 点击播放全片 | 28 / 19 / 27 MB |
| logo.mp4 / avatar.mp4 / modal.mp4 / shortcuts.mp4 | 悬停循环预览 | 0.8 / 0.2 / 0.2 / 0.7 MB |

悬停预览的 4 个都很小，不影响首屏；点击播放的 3 个是点击后才加载。

## 修改方法
- 改文字：编辑 index.html 里对应的 h3（标题）、p.work-desc（描述）、ul.tags（标签）。
- 换图：新图放进 assets/img/，改 src 与 data-images（多图英文逗号分隔）。
- 换视频：新视频放进 assets/video/，改 data-video（点击播放）或 data-loop（悬停预览）。
- 删作品：整段 article class="work" 删掉。
- 加作品：复制一段 article 放进对应板块的 div.works。
- 改技能/荣誉：在 id="skills" 那一节里改。

## 部署到自己域名
整个 site/ 目录 90 MB，纯静态。上传到 Nginx / GitHub Pages / Netlify / Vercel 都行。
想更快：把 assets/video/ 放对象存储或 CDN，改 index.html 里对应路径；再开 gzip/brotli。
